# Salt & Story Website

Static site for Salt & Story.

## Pages
- `index.html` — public homepage
- `login.html` — client login / account prototype
- `dashboard.html` — client dashboard prototype

## Assets
Shared brand artwork is stored in `assets/`.

## Live deployment
This repository is structured for GitHub Pages from the `main` branch root. Once Pages is enabled, updates committed to `main` publish automatically.

> The current login/dashboard are front-end prototypes. Authentication and data persistence use browser storage and are not production security.
